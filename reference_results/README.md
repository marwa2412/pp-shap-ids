# Retained Aggregate Results

These JSON files were copied from the camera-ready experiment evidence and
contain aggregate summaries, verification reports, and runtime/data metadata.
They contain no raw network feature rows or trained models. They are reference
outputs, not evidence that a fresh user has rerun the experiments.

The original raw-to-PP ASR decreases on initial random splits are 13.05 and
31.95 percentage points (UNSW-NB15 and ToN-IoT). Structured XGBoost holdout
decreases are 10.08 and 37.16 points. LR has different effects, including an
adverse ToN-IoT evaluation seed. Read the complete conditions and limitations
in the main README before comparing values.
